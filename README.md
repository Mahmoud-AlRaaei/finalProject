# نظام ذكاء صنعي لاكتشاف الأخبار الكاذبة باللغة العربية على منصة X

مشروع تخرج - كلية الهندسة المعلوماتية - قسم الذكاء الاصطناعي - جامعة حمص
إعداد: محمود الراعي، عبد السلام ابراهيم، بلال جوخدار، علي العباس، محمد الأبوحسنة
إشراف: الدكتور ناصر أبو صالح | العام الدراسي 2025-2026

## نظرة عامة

تطبيق ويب يستخدم نموذج AraBERT المُدرَّب على 6,000 خبر عربي متوازن للكشف عن الأخبار الكاذبة بدقة 99.67%.

## هيكلية المشروع

```
fake_news_project/
├── app.py                     # خادم Flask الرئيسي
├── requirements.txt           # المكتبات المطلوبة
├── templates/
│   └── index.html             # واجهة المستخدم
└── arabert_final_model/       # ملفات النموذج المُدرَّب (يجب إضافتها يدوياً)
    ├── config.json
    ├── model.safetensors
    ├── tokenizer.json
    └── tokenizer_config.json
```

## خطوات التشغيل

### 1. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 2. إضافة ملفات النموذج

انسخ ملفات نموذج AraBERT المُدرَّب (config.json, model.safetensors, tokenizer.json, tokenizer_config.json) إلى المجلد:

```
arabert_final_model/
```

### 3. تشغيل التطبيق

```bash
python app.py
```

### 4. فتح المتصفح

```
http://localhost:5000
```

## آلية العمل

```
المستخدم → واجهة الويب → POST /predict → تنظيف النص (clean_arabic_text)
→ Tokenization → نموذج AraBERT → Softmax → النتيجة (صادق/كاذب + نسبة الثقة)
```

## المتطلبات التقنية

- Python 3.10 أو أحدث
- يُفضّل توفر معالج رسومي (GPU) لتسريع الاستدلال، لكن النظام يعمل أيضاً على المعالج المركزي (CPU) بزمن استجابة نحو 500 ميلي ثانية.

## ملاحظة

النظام لا يحفظ أي بيانات أو استعلامات؛ كل التحليل يتم لحظياً في الذاكرة فقط.
